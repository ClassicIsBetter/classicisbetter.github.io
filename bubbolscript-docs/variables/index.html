Bubbolscript Documentation

Variables

1. Var

Variables are used to store strings and integers to be used anywhere in a script

Variables are very useful for storing information such as how many coins a user has

You can make a variable by putting "var [variable name] [value]" into a script

Here is an example of a variable being made and printed:

var

score 5

print

score

output:

5

Add and Sub

Add and Sub are used to add and remove integers from variables

Theses are very useful for editing someones score, making a countdown or anything else

You can add to a variable by using "add [variable] [value]" and take from a variable by using "sub [variable] [value]"

Here is an example of a variable being added to and subtracted from:

var

score 5

add score 5

print

score

sub score 2

print

score

output:

10

8
