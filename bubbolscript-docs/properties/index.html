Bubbolscript Documentation

Parents, Children and Properties

1. Children

Children are different instances in the workplace

They are very important for making things such as doors, cars, or anything else

To get a child in the workplace, use "getChild [instance name]"

getChild Part5

2. Values/Properties

Values can be used to edit different properties about instances

You can edit a value by using "setval [value to change] [new value]" on the same line that you have used to get an instance using getChild

Current values you can change are Position, Scale, Rotation and Text

To change an instance's position, scale and rotation, you must put the new values in a Vector3()

Here is an example of a part's position being edited in a script:

getChild Part1 setval position Vector3(1.0, 5.0, 5.0)

2. Player Properties

Current player properties are Speed, Jump Height and Gravity

getChild Part1 setval position Vector3(1.0, 5.0, 5.0)
